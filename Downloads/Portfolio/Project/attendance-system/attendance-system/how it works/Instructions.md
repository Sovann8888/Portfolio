

1. Welcome: Professor creates an account with full name \+ email, then verifies with the code sent — one account per professor.  
2. Professor adds students to a class — student ID, full name, major (optional), and subject.  
3. Professor can view all their classes on one dashboard (e.g. Cyber Security, Data Science & AI), each showing student count and session count.  
4. Opening a class shows students enrolled, sessions held, and a button to Start QR Attendance Session.  
5. Starting a session generates a live QR code ("Scan to Mark Attendance") that refreshes every second, restricted to students on school WiFi, with a live counter of students marked.  
6. Once a session ends, it's logged in the Attendance Session History (date/time, professor, status), and each student's attendance record updates (e.g. sessions attended 0/1, 0/2) — exportable as CSV.
